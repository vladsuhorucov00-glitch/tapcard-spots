# tapcard · точки роста

Инструмент поиска точек для продажи NFC-карт: показывает бизнесы, у которых высокий потенциал отзывов в Яндекс Картах и 2ГИС.

## Что делает

- Ищет объекты в радиусе 0,5–10 км по данным OpenStreetMap (Overpass API).
- Считает «потенциал» точки (0–100): категория бизнеса, наличие телефона/сайта, график, плотность вокруг, принадлежность к сети.
- Показывает горячие зоны — квадраты 400 м, где точек больше всего.
- Даёт список с оценкой A/B/C, фильтром и выгрузкой в CSV.
- Карта рисуется на canvas без внешних библиотек и тайлов, дороги подтягиваются из OSM.

## Категории и веса

| Вес | Категории |
|---|---|
| 10 | рестораны, барбершопы, салоны красоты, стоматологии, отели |
| 9 | кафе, СПА, клиники, ветклиники, автосервисы, фитнес, тату |
| 8 | бары, автомойки, автосалоны |
| 7 | фастфуд, пекарни, оптика, фотостудии, ювелирные, химчистки, коворкинги |
| 6 | цветочные, зоомагазины, мебель, турагентства |
| 5 и ниже | одежда, аптеки, супермаркеты |

## Формула оценки

```
score = вес×5
      + телефон 8
      + сайт 8
      + график 4
      + адрес 2
      - сеть 6
      + трафик (0…14, по плотности объектов в радиусе 300 м)
```

A ≥ 80, B = 60–79, C < 60.

## Файлы

- `index.html` — собранная страница (всё в одном файле).
- `index.template.html`, `styles.css`, `app.js` — исходники.
- `serve.ps1` — локальный сервер для разработки (порт 8125).

## Сборка

```powershell
$tpl = Get-Content index.template.html -Raw
$css = Get-Content styles.css -Raw
$js  = Get-Content app.js -Raw
($tpl.Replace('/*__CSS__*/', $css).Replace('/*__JS__*/', $js)) | Set-Content index.html -Encoding utf8
```

## Ограничения

- Данные OSM неполные: часть заведений без названия, телефона или адреса.
- Нет данных о количестве отзывов и рейтинге — их можно добавить через API Яндекс Карт / 2ГИС.
- Overpass API имеет лимиты: при частых запросах возможны задержки.
