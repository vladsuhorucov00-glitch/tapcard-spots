# tapcard · точки роста

Инструмент ищет точки для продажи NFC-карт: рестораны, барбершопы, салоны красоты, стоматологии, отели, клиники, автосервисы и другие места, где просят оставить отзыв в Яндекс Картах и 2ГИС.

## Что умеет

- Поиск в радиусе 0,5–10 км по данным OpenStreetMap.
- Работает **без интернета и без Overpass**: для городов из списка ниже в репозитории лежат сохранённые срезы OSM (`data/<город>.js`). Срез подгружается в браузер и фильтруется на клиенте.
- Если среза для города нет (или вы в другом районе) — пробует онлайн-запрос к Overpass API.
- Оценка «потенциала» точки (0–100): категория, наличие телефона/сайта, график, адрес, принадлежность к сети, плотность точек вокруг.
- Горячие зоны — квадраты 400 м, где точек больше всего.
- Список с приоритетом A/B/C, фильтром и выгрузкой в CSV.
- Карта на canvas без внешних библиотек и тайлов: работает даже при блокировке картографических CDN.

## Города с сохранёнными данными

Белгород и Москва (радиус 3 км от центра). Остальные города — онлайн через Overpass.

Добавить город:

```powershell
# 1) сгенерировать срез через официальный OSM API (работает там, где Overpass заблокирован)
powershell -ExecutionPolicy Bypass -File generate-tiles.ps1 -Slug omsk -Name "Омск" -Lat 54.9885 -Lon 73.3242 -Radius 3000

# 2) добавить город в SNAPSHOT_SLUGS в app.js

# 3) пересобрать index.html
```

## Категории и веса

| Вес | Категории |
|---|---|
| 10 | рестораны, барбершопы, салоны красоты, стоматологии, отели |
| 9 | кафе, СПА, клиники, ветклиники, автосервисы, фитнес, тату |
| 8 | бары, автомойки, автосалоны |
| 7 | фастфуд, пекарни, оптика, фотостудии, ювелирные, химчистки, коворкинги |
| 6 | цветочные, зоомагазины, мебель, турагентства |
| 5 и ниже | одежда, аптеки, супермаркеты |

## Формула оценки

```
score = вес×5
      + телефон 8
      + сайт 8
      + график 4
      + адрес 2
      − сеть 6
      + трафик (0…14, по плотности объектов в радиусе 300 м)
```

A ≥ 80, B = 60–79, C < 60.

## Файлы

- `index.html` — собранная страница (её и деплоит GitHub Pages).
- `index.template.html`, `styles.css`, `app.js` — исходники.
- `data/<slug>.js` — сохранённые срезы OSM (`window.TAPCARD_CITY`).
- `generate-tiles.ps1` — генератор срезов через api.openstreetmap.org (нарезка на плитки ~600 м).
- `generate-data.ps1` — старый генератор через Overpass (maps.mail.ru), оставлен как альтернатива.
- `serve.ps1` — локальный сервер для разработки (порт 8125).

## Сборка

```powershell
$tpl = [IO.File]::ReadAllText("$PWD\index.template.html", [Text.Encoding]::UTF8)
$css = [IO.File]::ReadAllText("$PWD\styles.css", [Text.Encoding]::UTF8)
$js  = [IO.File]::ReadAllText("$PWD\app.js", [Text.Encoding]::UTF8)
[IO.File]::WriteAllText("$PWD\index.html", $tpl.Replace('/*__CSS__*/', $css).Replace('/*__JS__*/', $js), (New-Object Text.UTF8Encoding($false)))
```

## Ограничения

- Сохранённый срез — это «фотография» OSM на дату генерации; телефоны и графики могут устареть.
- Срез покрывает круг заданного радиуса вокруг центра города, а не весь город.
- Живой поиск требует доступа к Overpass API; в некоторых сетях он заблокирован — тогда работает только срез.
